# Inventaire des médias

## Périmètre et niveau de preuve

Le relevé initial du 2026-10-21 énumérait 141 chemins média suivis par Git. Les catégories et usages ci-dessous sont déduits des chemins et des descriptions textuelles présentes dans le dossier. Les captures sous `docs/` sont des pièces documentaires/visuelles, pas une preuve de licence des médias du produit. Les 23 anciens SVG d’interface et de gabarit sous `asset/icons/legacy/` ont depuis été retirés après vérification qu’aucune source runtime ne les charge; les lignes correspondantes ont été supprimées de cet inventaire.

Pour **chaque chemin** listé ci-dessous, sauf déclaration de catégorie IA explicitement indiquée, les valeurs individuelles suivantes sont **non établies / à confirmer** : provenance précise (auteur/source/version), brief ou prompt, source éditable, retouches et droits/licence. Une indication d'origine IA héritée de MEDIA-001 à MEDIA-004 n'établit ni le prompt, ni le fichier source, ni les conditions de droits de chaque ressource. L'audit technique du 2026-10-28 a examiné signatures, dimensions, tailles et empreintes SHA-256 de 70 médias alors suivis sous `asset/`; il n’a pas été relancé dans cette mise à jour. Les chemins déplacés ont été réconciliés avec le checkout courant sans recalculer les empreintes. Les trois calques hero présents dans `asset/` et les trois médias récents ajoutés à la table n’étaient pas couverts par ce relevé. Les mesures datées restent des observations de leur scan respectif, pas une inspection visuelle pixel par pixel ni une preuve de provenance ou de droits.

Le propriétaire a fourni le 2026-11-19 la source `Monnaie_fond_transparent.png`, copiée sans retouche dans `frontend/public/assets/icons/ui/points.png`. Son SHA-256 runtime est `24a670d71339bb3c98216fc55b4c710c65c7a33eff69b58f745470bd699e2886`; le brief, les conditions de droits et une source éditable distincte restent inconnus.

Cartographie statique et relevé binaire : la colonne « Référence code » relie un chemin à une déclaration, un registre ou une route d’assets; seule une assertion d’exécution datée est notée comme observée, limitée à cette cible. Une référence de code ne prouve pas que le média soit rendu. Le contrôle local Docker du 2026-10-29 avait observé les réponses SSR publiques et le téléchargement HTTP de trois icônes de marque, sans session authentifiée ni médias après hydratation. Les colonnes poids, SHA-256, signature/dimensions et commit conservent leurs dates indiquées; elles ne valent pas une nouvelle mesure courante, ni une preuve d’origine, de droits ou d’usage effectif. Les noms de tests et références documentaires ne sont pas pris comme call sites runtime.
