# Remplacement des visuels de la vitrine

## Objectif

Remplacer les trois scènes de la vitrine qui représentaient une femme par des scènes équivalentes avec l’homme fourni comme référence, en conservant les cadrages, les environnements, les lumières et le style photo.

## Périmètre

- image de consultation d’un stream
- image d’installation de l’extension
- image de découverte d’une récompense
- textes alternatifs associés

## Contrôles

Les visuels sont inspectés avant intégration. La vitrine est contrôlée par les tests frontend, le typecheck, le lint, le build et les contrôles responsive/accessibilité de la CI.
